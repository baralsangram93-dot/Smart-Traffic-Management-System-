# Smart Traffic Management System

Tech Stack: Arduino Uno, C++, 8x IR Sensors

Developed a Smart Traffic Management System using Arduino Uno and 8 IR sensors to detect vehicle density at a 4-way junction. Programmed in C++ to automatically adjust traffic signal timing based on real-time traffic, which reduces congestion and waiting time.

Components Used: Arduino Uno, IR Sensors, LEDs, Jumper Wires

Working: IR sensors count vehicles on each side and Arduino changes green light duration accordingly.
